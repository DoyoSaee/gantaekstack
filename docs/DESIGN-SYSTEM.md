# 간택스택 디자인 시스템 — 구현 지침

> **이 문서는 참고자료가 아니라 규칙입니다.** UI를 만들거나 고칠 때 여기 적힌 대로 하세요.
> 근거: `app/globals.css`(토큰 실값) · `app/layout.tsx`(서체) · `docs/logo-design/`(마크·표정·보이스).
> 여기서 새로 정한 것(코드에 아직 없는 것)은 §10에 따로 표시했습니다.

## 0. 원칙 네 가지

이 시스템의 모든 규칙은 이 넷에서 나옵니다. 판단이 갈리면 여기로 돌아오세요.

1. **그림자를 쓰지 않는다.** 깊이는 `bg-page → bg-card → bg-raised` 세 단계와 선 한 겹으로만. `box-shadow`, `drop-shadow`, 그라디언트 전부 금지.
2. **액센트는 라즈베리 하나뿐이고, 한 화면에 한 곳.** 두 곳에 쓰는 순간 어느 쪽도 중요해 보이지 않는다.
3. **숫자와 기술명은 전부 Mono.** 데이터와 말을 눈으로 갈라둬야 "우리가 센 사실"과 "우리가 하는 말"이 구분된다.
4. **제목은 900, 본문은 400.** 그 사이 굵기는 강조 어구(500)와 카드 제목(700)에만.

제품의 태도와 같습니다 — **채점하지 않고 방향을 가리킨다.** 화면은 데이터를 건조하게 늘어놓고, 감정은 고양이 표정 하나와 짧은 한마디로만 냅니다.

값은 전부 `app/globals.css`에 이미 있습니다. 아래는 **어디에 쓰는지**입니다. 하드코딩하지 말고 변수로 쓰세요.

| 카드 위 한 단 | `--muted` / `--secondary` | `#EAEBED` | `#3A3B3F` |
| 반전 면 | `--foreground` 면으로 | `#28272A` | `#FEFEFE` |
| 본문 | `--foreground` | `#28272A` | `#FEFEFE` |

- **차콜은 순서대로만 겹친다**: `#28272A → #313538 → #3A3B3F`. 건너뛰지 않습니다.

- 기술명·퍼센트·건수·연도는 **예외 없이 Mono**. 뱃지 안에서도, 툴팁 안에서도.

### 여백 · 반경 · 선

여백은 4의 배수만: `4 · 8 · 12 · 16 · 24 · 32 · 40 · 64`.
- 카드 안쪽: 작은 카드 16, 큰 카드 32 · 카드 사이 24 · 섹션 사이 40 · 화면 위아래 64.

반경(`--radius: 0.625rem` 스케일):
- `6px` 뱃지·작은 칩 · `8px` 버튼·입력창·직군 탭 · `10px` 카드 · `14px` 큰 패널 · `999px` 지역 탭·BETA·마크 획 끝 · `24px` 앱 아이콘 타일(104px 기준)

선 굵기 = 위계:
- `1px` 카드 테두리·구분선 · `1.5px` 보조 버튼 외곽선·활성 직군 탭 · `4px` 라즈베리 띠(액센트를 쓰는 유일한 "선" 형태)

### 투명도 · 고정 치수

- `0.07` 마크 워터마크 · `0.4` 비활성 · `0.9` 면 있는 버튼 호버
- 컨트롤 높이 `40px`(= 최소 터치 타깃) · 보조 칩 `28px`(세로 여백으로 40 확보)
- 마크: 헤더 `36px`, 본문 셸 `28px`, **최소 `56px`**, 앱 아이콘 타일 `104px`
- 폭: 읽는 화면 `768px` · 보는 화면 `1024px` · 본문 단락 `620px` · 카드 설명문 `560px`

## 2. 부품

### Card
`bg-card` + `border` 1px + 반경 10px. **그림자 없음** — 떠 보이는 이유는 바탕이 반 단계 어둡기 때문.
- 헤더(제목 h3 + 설명 caption) / 본문은 여린 hairline으로만 가름
- 카드 안에 카드를 넣지 않음. 중첩이 필요하면 `bg-raised` 블록
- 호버는 배경이 아니라 **테두리**를 `foreground`로 올림
- 변형: 액센트 카드(왼쪽 4px 띠, 화면당 하나) · 링크 카드(제목 뒤 `→`) · 스탯 카드(라벨 위, 수치 아래)

### Button — 4단계
| 단계 | 모양 | 쓰는 곳 |
|---|---|---|
| 강조 | 라즈베리 면 + `#FEFEFE` | **화면당 하나뿐인** 다음 행동 |
| 기본 | 반전 면(차콜) + 반전 글자 | 부차적이지만 확실한 행동 |
| 보조 | 투명 + 1.5px 외곽선 | 대안 입력 경로 |
| 조용한 | 투명 + muted 글자, 굵기 400 | 되돌릴 수 있는 편의 |

- 비활성은 `opacity: 0.4`. 회색으로 갈아끼우지 않음
- 진행 중 라벨은 표정을 앞에: `ㅡㅅㅡ 분석 중…`. **스피너 금지**
- ⚠ 강조 버튼 글자는 **16/700 이상**. 14/700은 대비 미달(§5)

### Field — 입력 5상태
| 상태 | 모양 |
|---|---|
| 기본 | border 1px, 반경 8px, 플레이스홀더 muted |
| 포커스 | 테두리를 foreground로 + `ring` 1px outline(offset 1) |
| 드래그오버 | 테두리를 **점선**으로 + 배경 `bg-raised` |
| 에러 | 테두리 `destructive` + 아래 12px 설명 한 줄 |
| 비활성 | `opacity: 0.4` |

- **색으로 상태를 알리지 않음.** 포커스는 굵기·링, 드래그오버는 선의 종류. 유일한 예외가 에러
- 에러 문구는 **무엇을 하라고** 말함: "오류 발생" ✗ → "스캔본이면 텍스트를 직접 붙여넣어 주세요" ✓
- 높이 고정하지 않고 `resize: vertical` 허용

### Tabs — 축이 다르면 모양이 다르다
- **지역(상위)**: 알약(반경 999), 14px, 활성 = 반전 면
- **직군(하위)**: 네모 칩(반경 8), 12px, 활성 = 테두리 1.5px + 굵기 500
- 활성 칩은 **면을 채우지 않음**. 반전 면은 상위 축 하나만
- 라즈베리 금지 — 탭은 "지금 어디를 보고 있나"일 뿐
- 링크(`<a href>`)로 구현해 **URL이 곧 상태**. 공유하면 같은 필터가 열림
- 8개를 넘으면 줄바꿈. **스크롤 박스 금지** — 가려진 필터는 없는 필터

### Badge
| 변형 | 모양 | 뜻 |
|---|---|---|
| 채운 | `bg-raised` 면 | 내 스택, 추천 기술 |
| 외곽선 | 투명 + 1px | 계산된 값, 파생 정보 |
| 숨은 요구 칩 | 외곽선 + `·38` | 공고 문장에서 뽑은 요구 역량 |

- 채운 것과 외곽선을 **한 줄에 섞지 않음**
- 뱃지는 누를 수 없음(누르는 건 Tabs의 칩)
- 숨은 요구는 **문장 그대로**. 요약하지 않음 — 공고에 그렇게 쓰여 있다는 게 정보

### DataRow — 왼쪽은 무엇, 오른쪽은 얼마
테두리로 감싸지 않고 행 사이 선 한 겹(`divide-y`)으로만 나눔.

추세 라벨은 **색이 아니라 화살표와 굵기**로 구분:
| 라벨 | 모양 |
|---|---|
| `↑ 상승` | 보조 색(`#4A4B4F` / `#B9BBBF`) |
| `→ 유지` | muted |
| `↘ 완만한 감소` | muted |
| `↓ 뚜렷한 감소` | **foreground + 굵기 500** (가장 진하게) |
| `신생 · 현역` | muted, 정점 대신 `등장 2020년~` |

- **`↑ 상승`에 라즈베리를 쓰지 않음.** 상승 기술이 여러 줄이면 액센트가 흩뿌려짐. 가장 진한 것은 **할 말이 가장 많은 줄**(뚜렷한 감소)
- `↓ 뚜렷한 감소`는 "사장됐다"가 아님 — 카드 설명문에 반드시 "신규 채택 비중이 줄었다는 뜻"을 적을 것

### Metric
- **답** `metric-xl` 48/500, 앞에 표정, 뒤에 해설 한 구절 — **화면당 하나**
- **스탯** `metric` 30/500, 위에 caption 라벨 — 한 줄에 3장까지
- 근사값에는 `≈`. 무게중심은 계산값이지 관측값이 아님
- 값이 이름이면 26px로 내림(글자는 숫자보다 넓음)
- **라즈베리 금지** — 큰 숫자는 이미 충분히 큼

### Chart
- 데이터는 **무채색만**(`--chart-1`…`--chart-5`). 계열은 색이 아니라 **순서와 굵기**로 구분
- 격자선은 **가로만**, `border` 색. 세로 격자선·축선 금지
- 막대 반경 5–6px, 트랙 `--chart-5`, 높이 14px
- 범례 금지(계열이 하나면 카드 설명문이 범례) · 축 제목 금지(단위는 값에 붙임)
- `role="img"` + **곡선이 말하는 바를 문장으로 담은** `aria-label`
- 강조는 한 요소만(1위 막대 하나, 또는 구간 하나)

### Tooltip
`bg-card` + 1px + 반경 8px. **값만 말함** — 해석은 카드 설명문이나 AI 총평의 몫.
- 받침 줄에 **단위의 출처**(`전체 공고의 31.3%`)
- 색 점 범례 금지(무채색이라 구분 안 됨)
- **터치 기기엔 툴팁이 없음** → 값을 툴팁에만 두지 말 것. 랭킹은 막대 옆에 항상 숫자를 적어둠

### EmptyState — 대기 · 빈 · 실패 · 완료
틀은 하나: **표정 · 제목 한 줄 · 설명 한 줄 · (있으면) 되돌릴 행동 하나**
- 대기/빈/실패는 **전부 `ㅡㅅㅡ`**. 실패에 `ㅇㅅㅇ`를 쓰지 말 것 — 실패는 놀랄 일이 아님
- `^ㅅ^`는 **진짜 완료에만**
- 사과하지 않음. 무엇이 없는지 말하고 되돌릴 길을 줌
- 상태 화면에 강조 버튼을 두지 않음 — 여기는 막다른 길이지 갈림길이 아님
- **조용한 실패 금지** — 시대 곡선과 매칭 안 된 기술은 목록으로 보여줌

### Skeleton
`bg-raised` 블록, 반경 6(글자 자리) / 8(덩어리).
- **깜빡이지 않음**(shimmer·pulse 금지)
- 길이를 실제 데이터 분포대로 들쭉날쭉하게 — 전부 같으면 로딩 끝날 때 화면이 튐
- **행 개수를 실제와 맞춤**(TOP 20이면 20줄)
- 3초 넘길 작업엔 스켈레톤 대신 `ㅡㅅㅡ` + 진행 문구

### Toast
- **발견**: 반전 면 + `ㅇㅅㅇ` + **반드시 숫자 포함**(`지난 분기보다 2.4배, 11위`)
- **조용한 확인**: `bg-card` + 1px, 표정 없음(`복사했습니다 ✓`)
- **사람이 읽고 결정해야 하는 것은 토스트에 담지 않음** — 4초 뒤 사라지는 자리
- 닫기 버튼 없음(시간이 닫음) · 한 번에 하나 · 라즈베리 금지

### Link — 네 종류 전부 파란색 아님
| 종류 | 모양 |
|---|---|
| 인라인 | foreground + 밑줄 1px, offset 3px |
| 되돌아가기 | `←` + 13px muted, 밑줄 없음 |
| 출처 | 12px muted + 밑줄, offset 2px |
| 카드 | 카드 전체가 링크, 제목 뒤 `→`, 호버 시 테두리만 |

**밑줄이 링크의 표시.** 색으로 구분하지 않음 · 외부 링크 아이콘(`↗`) 금지 · 방문 링크 색 변경 금지

### AppShell
헤더에는 **마크 · 이름 · 단계 · 현재 위치**만. 검색·계정·설정·알림 없음(로그인 없는 서비스).
- 현재 페이지는 foreground + 굵기 500, 나머지 muted. 밑줄·배경 금지
- 홈에서는 헤더 대신 **히어로 안의 브랜드 락업** — 첫 화면에 마크가 두 번 나오면 안 됨
- 푸터는 **출처를 전부 적는 자리**. 아직 없는 것도 적음(`민간 API 승인 대기`)
- 셸에 라즈베리 금지

### SectionHead
```
[eyebrow · 대문자 로마자·숫자만]
제목                                    [보조 행동 하나까지]
설명 한 줄 — 무엇을 세었고 무엇이 아닌지
```
**설명문은 방법을 적음.** "지금 뜨는 기술" ✗ → "공고 본문에서 AI가 추출·정규화·분류한 기술을 세어 정렬" ✓. 이 제품의 신뢰는 전부 여기서 나옴.

## 3. 마크와 표정

마크는 **"ㄱ이 머리다"** — ㄱ의 가로획이 이마, 세로획이 오른쪽 윤곽, 그 안에 `ㅌㅅㅌ`. 눈의 3단 획이 지표 막대와 같은 어휘.
파일: `public/logo.svg`(기본형) · `app/icon.svg`(축약형, 앱 아이콘).

- 여백은 ㄱ 세로획 굵기의 **네 배**를 사방에
- 최소 크기 화면 56px / 인쇄 16mm. 그 아래로는 **획만 굵히고 눈은 어떤 크기에서도 3단**
- 기울이기·늘이기·그림자·그라디언트·테두리 추가 금지 · 사진 위 금지
- 배경은 Paper · Ink · 라즈베리 **단색 위에만**
- 다크에서 기본형은 `dark:invert`. 앱 아이콘은 뒤집지 않음(라즈베리 타일이 SVG 안에 있음)

**표정은 상태에 1:1로 매핑.** 기분에 따라 고르지 않습니다. 입 `ㅅ`은 고정, 눈만 바뀝니다.

| 표정 | 상태 | 쓰는 곳 |
|---|---|---|
| `ㅌㅅㅌ` | 뚱함 · 기본 | 격차가 클 때. 로고·앱 아이콘 |
| `ㅡㅅㅡ` | 체념 · 대기 | 로딩, 빈 화면, 실패 |
| `ㅇㅅㅇ` | 놀람 · 발견 | AI 총평, 급상승 알림 |
| `^ㅅ^` | 만족 · 달성 | 격차가 메워졌을 때. **남용 금지** |

- **한 화면에 표정은 하나.** 액센트 규칙과 같음
- 코드가 상태에서 **계산**함(`era.gapYears > 0.4 ? "ㅌㅅㅌ" : "^ㅅ^"`). 손으로 고르지 않음
- **항상 `aria-hidden="true"`** — 스크린리더에 낱자로 읽힘
- 색은 foreground. 라즈베리로 칠하지 않음 — 표정은 강조가 아니라 상태
- **네 개가 전부.** 새 표정을 만들지 말 것

## 4. 아이콘

**텍스트 글리프 9개가 전부입니다.** SVG 아이콘 라이브러리를 들이지 마세요 — 아이콘이 열 개를 넘는 순간 그것도 관리해야 할 시스템이 됩니다.

| 글리프 | 뜻 | 위치 |
|---|---|---|
| `→` | 이동 · 다음 | 제목 **뒤** |
| `←` | 되돌아가기 | 글자 **앞** |
| `↑` `→` `↘` `↓` | 상승 · 유지 · 완만한 감소 · 뚜렷한 감소 | 추세 라벨 앞 |
| `≈` | 근사 | 계산값 앞 |
| `·` | 구분 | 메타 정보 사이(쉼표 대신) |
| `✓` | 완료 | 되돌릴 수 있는 완료에만 |

- **크기·색을 지정하지 않음.** 옆 글자에서 물려받음. 글리프가 글자보다 커지면 그 순간 아이콘 시스템이 필요해짐
- 뜻이 글자로도 적혀 있으면(`↑ 상승`) `aria-hidden`. 글리프만 있으면(`시장 대시보드 →`) 읽히게 둠

## 5. 화면 조립

### 폭
- 읽는 화면(홈, 진단 결과) **768px** · 보는 화면(대시보드) **1024px** · 본문 단락 620px · 카드 설명 560px

### 액센트를 어디에 둘 것인가
기준: **"이 화면에서 사람이 다음에 할 일 또는 알아야 할 단 하나."**

| 화면 | 액센트 | 왜 |
|---|---|---|
| 홈 | `내 스택 시대 진단` 버튼 | 이 화면에서 할 일은 그것 하나 |
| 진단 결과 | 주류도 곡선 위 **격차 구간** | 연도 숫자가 아니라 "지금과 얼마나 떨어져 있나"가 답 |
| 시장 대시보드 | **1위 막대** | 시장이 지금 가장 세게 간택한 것 |

나머지는 전부 차콜 단계로. 액센트를 쓰는 형태는 셋뿐: **면**(버튼, 막대 하나) · **띠**(4px — 카드 왼쪽 변, 밑줄) · **점**(차트 위 한 점).

### 결과 화면의 순서
1. **한 숫자** — 화면의 답
2. **그 숫자를 쪼갠 축** — 직군별(한 숫자로 뭉뚱그리면 왜곡됨)
3. **모양** — 곡선이나 막대
4. **줄 단위 근거** — 기술별 리스트
5. **말** — AI 총평. **데이터 다음에 옴. 절대 먼저 오지 않음**
6. **다음 걸음** — 부족 기술 추천

## 6. 접근성

**구조적으로 위험한 지점 세 군데.**

### 라즈베리 대비 미달
| 조합 | 대비 | 판정 |
|---|---|---|
| 흰 글자 on 라즈베리 | **3.96:1** | 본문 크기 ✗ / 24px 또는 18.66px 볼드 ✓ |
| 라즈베리 글자 on Paper | **3.66:1** | 본문 크기 ✗ |

→ 라즈베리는 **면·선·점**으로. 글자로 쓰려면 16/700 이상.
→ 차트의 라즈베리 구간 **라벨은 foreground로**. 선은 라즈베리, 글자는 차콜.
→ 비텍스트 대비(선·테두리·그래프)는 3:1을 넘으므로 통과. 거기까지가 안전 범위.

### `--muted-foreground`의 여유가 없음
`#6E7075` on `#F4F5F6` = **4.54:1** (기준선 +0.04).
- **13px 아래로 내리지 말 것**
- **`bg-raised`(#EAEBED) 위에 올리지 말 것** — 4.2:1로 떨어짐. 뱃지 안 보조 숫자가 그 경우 → `#4A4B4F`를 쓰거나 뱃지 배경을 카드색으로
- 더 흐리게 하고 싶으면 색이 아니라 **크기와 위치**로

### 표정과 화살표가 읽힘
- 표정은 **항상 `aria-hidden`**. 뜻은 옆 문장이 전함
- 화살표는 뜻이 글자로도 있을 때만 숨김
- `≈`는 읽히게 둠("약"으로 읽힘)

### 그 밖
- `outline: none` 금지. 포커스는 `--ring` 1px + offset
- 탭은 `role="tablist"`/`role="tab"`/`aria-selected`. 링크로 구현해도 `aria-current="page"`
- 비활성은 `opacity: 0.4`라 대비가 무너짐 → 중요한 정보를 적지 말고 `aria-disabled`와 함께 **왜 잠겼는지** 옆에 적을 것(`최소 20자부터`)
- 모든 상호작용 요소는 40px 이상 터치 타깃

## 7. 반응형

중단점은 **`768` / `1024` 두 곳뿐**. 중간 단계를 만들지 않습니다.

| 폭 | 바뀌는 것 |
|---|---|
| < 768 | 그리드 1열 · 화면 여백 64→24 · 히어로 40px→30px |
| 768–1023 | 스탯 2열 · 링크 카드 2열 · 랭킹 행에서 건수를 버리고 비율만 |
| ≥ 1024 | 스탯 3열 · 대시보드 전체 폭 |

- **랭킹 20줄을 줄이지 않음.** 접기·"더 보기" 금지. 대신 건수를 먼저 버리고 비율을 남김
- **탭을 스크롤 박스에 넣지 않음.** 줄바꿈
- 진단 행의 오른쪽 묶음은 좁아지면 **아래로 떨어뜨림**. 줄임표로 자르지 않음 — 잘린 숫자는 틀린 정보
- 차트는 `viewBox`로 비례 축소. **세로를 줄이지 않음**(곡선이 납작해지면 봉우리가 사라짐)
- 폰트에 `vw` 금지 · 모바일 전용 내비(햄버거·바텀시트) 금지 · 인쇄 스타일 대신 **URL 공유**(`/?s=React,TypeScript`)가 이 제품의 내보내기

## 8. 다크

라이트를 뒤집은 게 아니라 **차콜 3단을 그대로 쌓아 올린 것**. 두 테마 모두 **"올라올수록 밝아진다"** 규칙 하나로 돕니다.

- **라즈베리는 두 테마 공통 `#F32859`.** 다크에서 밝히거나 채도를 낮추지 않음
- `--border`가 다크에서 `#3A3B3F`로 `bg-raised`와 **같은 값인 것은 의도** — 경계는 카드 자체의 단차가 만듦
- **순수 검정(#000) 금지.** 바탕 `#28272A`가 가장 어둡고 그 아래는 없음
- 다크에서 그림자를 되살리지 않음 · 다크 전용 색을 새로 만들지 않음 · 테마 전환 애니메이션 금지
- 차트 계열은 다크에서 **순서가 뒤집힘**(`--chart-1`이 흰색). 값이 아니라 역할을 따라갈 것

**새 화면은 두 테마에서 눈으로 확인:** ① 카드가 바탕에서 떠 보이는가 ② `bg-raised` 위 muted 글자가 읽히는가 ③ 라즈베리 한 곳이 여전히 한 곳인가

## 9. 모션

**모션 토큰이 없습니다.** 의도적으로 비운 자리입니다.

쓰는 것 — 호버 `150ms ease-out`(테두리·투명도·배경), 토스트 나타남/사라짐 `100ms`(투명도만). **그게 전부.**

쓰지 않는 것:
- **스피너** → `ㅡㅅㅡ` + 지금 뭘 하는지 적은 문구
- **스켈레톤 깜빡임**(shimmer, pulse)
- **차트 그리기 애니메이션** — 이 서비스는 결과를 공연하지 않음
- **숫자 카운트업** — `≈ 2019년`이 0부터 올라가면 그건 극이지 데이터가 아님
- 페이지 전환 효과 · 패럴랙스 · 스크롤 연동 등장 · 테마 전환 애니메이션

**왜:** 움직임은 어느 것이든 강조이고, 강조는 화면당 한 곳으로 이미 예산이 잡혀 있음. 라즈베리 한 곳을 지키려고 색을 억제해놓고 모션으로 강조를 다시 뿌리면 규칙 전체가 무의미해짐. **감정은 표정이 냄, 움직임이 아니라.**

`prefers-reduced-motion: reduce`에서는 위 두 가지도 끔.
